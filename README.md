# Dan Žalud – Oficiální web fitness trenéra & závodníka NPC Bodybuilding

Moderní one-page web na míru pro fitness trenéra a NPC závodníka **Dana Žaluda** ([@dan_zalud](https://instagram.com/dan_zalud)).

> *„Pomůžu ti nabrat svaly a hubnout srozumitelně.“*

---

## 💎 Vizuální styl & Designový systém
- **Tmavý režim (Dark mode):** Uhlově černá (`#0d0d10`), prémiové tmavě šedé karty (`#17181c`), vysoce kontrastní bílé texty (`#f9fafb`, `#9ca3af`).
- **Akcentní barva:** Zlatá / jantarová (`#e5a93c`, `#f59e0b` s jemným glow efektem), evokující medaile, pódium a profesionální úroveň kulturistiky.
- **Typografie:** Masivní bezpatkový font **Syne** pro nadpisy a vysoce čitelný **Plus Jakarta Sans** pro texty.
- **Mobile-first architektura:** Optimalizováno pro 95 %+ návštěvníků přicházejících z Instagramu na mobilních zařízeních (včetně fixní spodní CTA lišty a responzivního menu).
